04 // JAVASCRIPT LOGIC CONTROLLERS (scripts/)
scripts/main.js CORE CONTROLLER

The central orchestrator of interactive HUD events:

  • Uptime & Telemetry: Calculates live uptime clock and simulated frame time.
  • Scrollspy: Detects section scroll position and updates top nav indices (01 to 08).
  • Theme Engine: Toggles body theme class and saves user selection to localStorage.
  • Contact API Dispatch: Collects form data and issues asynchronous fetch('/api/contact').
scripts/sound-fx.js AUDIO SYNTHESIZER

Procedural Web Audio API sound generator:

  • Zero Audio Files: Synthesizes custom sine and square waves at runtime (tactile clicks, laser chimes).
  • Safe Browsing: Respects browser autoplay restrictions; remains muted until the user clicks the top bar audio toggle.
scripts/physics-sandbox.js NETCODE SIMULATION

Interactive 2D physics & netcode lab:

  • Demonstrates client-side prediction, server authoritative reconciliation, jitter buffers, and simulated packet loss.
worker.js & build.js CLOUDFLARE EDGE

Serverless Edge Router & deployment hook:

  • worker.js: Routes /api/contact and falls back to static files.
  • build.js: Automatically injects RESEND_API_KEY during Cloudflare deploy while keeping GitHub repository clean.
05 // LOCAL DEVELOPMENT & GIT DEPLOYMENT WORKFLOW
Running Locally (5 Seconds) DEV WORKFLOW

No npm installs or build steps needed. Run directly in PowerShell:

python -m http.server 8080

Then open http://localhost:8080 in Chrome to test changes in real time.

Pushing Updates to Production DEPLOYMENT

Deploying changes to mayankmanjul.com is a standard 3-command git workflow:

git add .
git commit -m "feat: update project details"
git push origin main

Cloudflare automatically detects the push, runs build.js, and publishes the update live in ~60 seconds.
